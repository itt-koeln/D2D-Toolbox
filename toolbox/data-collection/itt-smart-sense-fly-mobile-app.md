## Background

ITT Smart Sense Fly is an Unmanned Aerial Vehicle (UAV) based solution to capture aerial photographs of study region using a camera and other sensors. This solution a custom mobile has been developed to enables researchers, scientists, and students to capture aerial photographs using selected drones without having to learn how to pilot the drone. This enables the researchers to concentrate on analyzing the collected data rather than spending months (sometimes years) in data collection.

## Principle

The ITT Smart Sense Fly app is a mobile application that allows the user to create flight plans, pilot the drone, capture aerial pictures, and videos. This elegant mobile app can run on any android phone or tablet. The app pilots and controls the autonomous drone according to the preconfigured algorithm. The app is the perfect tool to automatically capture image data to generate optimal 2D, 3D maps, and models.

## Manual

The ITT Smart Sense Fly app has an intuitive user interface with a couple of major screens. The sequence of steps to pilot the drone using the app is given below.

1. The user selects the region of interest by placing the markers on map section on the main screen.
2. Adjusts the flight settings if required, by tapping on “Flight Settings” button.
3. Taps any of the four “flight plan buttons” available.
4. Taps “Start” button to start the mission.

## Example

The app has been used to conduct an aerial survey over 9 acres using DJI Matrice 100 drone and captured 120 photographs. These photos were then processed to create high resolution orthomosaic and Digital Elevation Model of the region.
