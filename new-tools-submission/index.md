# Submit a tool

The D2D Toolbox is built by its users. If you have developed or documented a method, model, dataset or training resource that fits the data-to-decision chain, you are welcome to contribute it.

## How it works

1. Download the [tool description template]({{ '/new-tools-submission/tool-description-template/' | relative_url }}) and fill it in – background, principle, step-by-step manual, requirements, strengths and limitations, references.
2. Send the filled template with figures and any supporting files (PDF, scripts, data samples) to the toolbox administration by e-mail.
3. The contribution is reviewed for completeness and consistency with the other tools, formatted and published under your name.
